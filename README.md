# Tally

個人経営バー向けの会計・伝票管理Webアプリです。現在は主要画面と操作導線を確認できるフロントエンド・プロトタイプです。

## 起動

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

## 実装済みの画面・操作

- 卓一覧と空席／使用中表示
- 伝票の商品追加、数量増減、削除
- カテゴリ絞り込み
- 会計と支払い方法選択（現金・QR・売掛・その他）
- 会計履歴
- オーナーPIN画面（デモでは任意の4桁）
- 日次集計画面
- タブレット、スマートフォン向けレスポンシブ表示

## 本番運用に必要な次工程

SupabaseのDB・Auth接続、RLS、永続化、営業日計算、印刷、操作履歴、設定CRUDを追加する必要があります。
